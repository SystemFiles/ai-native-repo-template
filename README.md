# AI-native repo template

A minimal starting point for a long-lived repo that humans and agents share:
agent instructions, architecture decision records, Conventional Commits, and
SemVer releases.

## Use this template

On GitHub, choose **Use this template**, then **Create a new repository**.

## Customize

- `README.md`: say what the new repo is.
- `AGENTS.md`: replace the overview and commands placeholders.
- Register an ARC runner named after the new repo. The workflows already
  use that name, and they stay queued until the runner exists.
